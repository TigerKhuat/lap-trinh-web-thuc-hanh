# Web Lab - ReactJS + React Router

Bài thực hành môn Lập trình web.

## Nội dung đã làm
- Tạo project ReactJS bằng Vite
- Giao diện trang chủ (HTML + CSS)
- Các page: Trang chủ, Sản phẩm, Giới thiệu, Liên hệ
- Tích hợp React Router để chuyển trang bằng menu và URL

## Chạy project
```bash
npm install
npm run dev
```
